Settings

How often this identity automatically broadcasts an announce so peers can find and route to it. Manual announces via the megaphone icon work regardless of this setting.
⚠ Radio settings are device-wide — they apply to every identity stored on this device, not just the one you're logged into. Changing them reboots the radio and may interrupt active conversations.

Pick the region preset that matches your local LoRa community. Both ends of a conversation must use the same region settings — if one device uses EU 869 and the other US 915, they won't hear each other.

SF7 + BW 125k + CR 4/5 is the speed-optimised default. SF11+ trades speed for range and lowers duty-cycle headroom — useful for long links.
Airtime caps are regulatory limits — picking a region preset sets a sane default; 0 disables (only use where allowed).
