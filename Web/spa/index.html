How often this identity automatically broadcasts an announce so peers can find and route to it. Manual announces via the megaphone icon work regardless of this setting.
⚠ Connectivity settings are device-wide — they apply to every identity stored on this device. Changing radio params reboots the device and may interrupt active conversations.
LoRa Radio

Pick the region preset that matches your local LoRa community. Both ends of a conversation must use the same region settings — if one device uses EU 869 and the other US 915, they won't hear each other.

SF7 + BW 125k + CR 4/5 is the speed-optimised default. SF11+ trades speed for range and lowers duty-cycle headroom — useful for long links.
Airtime caps are regulatory limits — picking a region preset sets a sane default; 0 disables (only use where allowed).

Serial / diagnostics
Turn OFF if you're reading the USB serial with pio device monitor or similar — KISS-framed binary bytes are otherwise interleaved with the diagnostic text log. Leave ON if you're using the device as a KISS host for tools like rnsd or MeshChat. Persists across reboots.

LXMF stamps each outbound message with the sender's wall-clock time so peers display them with the right timestamp. The device picks the highest-priority enabled source whose driver has reported a value.
