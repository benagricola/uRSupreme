μRSupreme Web Flasher

μRSupreme makes a LilyGo T-Beam Supreme a standalone Reticulum / LXMF mesh node with a built-in chat client. You reach it from any browser on the same network. There's no host computer involved.

It builds on microReticulum_Firmware, which puts the microReticulum C++ stack on top of RNode firmware. The fork adds the user interface: a web app for LXMF chat with attachments, multi-identity support, GPS and sensor telemetry, and discovery announces for community-map listeners like rmap.world.

Plug a LilyGo T-Beam Supreme into your computer via USB, then click the button that matches your variant. Your browser talks to the device over Web Serial; no toolchain or terminal involved.

Your browser doesn't support Web Serial. Use a Chromium-based browser (Chrome, Edge, Brave, Opera) on a desktop OS. Firefox and Safari don't ship Web Serial yet.

What this does

  • Downloads the latest .factory.bin from the latest release.
  • Asks you to pick the USB-serial port the device shows up on.
  • Erases the flash and writes the full firmware image in one shot.
  • Reboots the device and, over the same USB-serial port, prompts you for the SSID + password of the WiFi network you want it on (Improv WiFi).
  • Once the device joins, the page hands you back a link straight to its web app. No softAP hop required.

Already flashed? Reconfigure WiFi without re-flashing

If a device is already running this firmware and you just need to move it to a different network, plug it in, click the same install button above, pick its port, and choose Configure WiFi in the dialog that appears. The button detects an already-flashed device over Improv and offers reconfiguration options instead of re-flashing.

If the device isn't recognised

  • Try a different USB cable. Some are charge-only and don't carry data.
  • If the chip never appears in the port list, hold the BOOT button while plugging in to force ROM download mode.
  • On Linux you may need sudo usermod -aG dialout $USER (then log out + back in) for the browser to see the port.
