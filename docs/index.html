μRSupreme — Web Flasher

Plug a LilyGo T-Beam Supreme into your computer via USB-C, then click the button that matches your variant. Your browser talks to the device over Web Serial; no toolchain or terminal involved.

T-Beam Supreme V1 — SX1262

The classic Supreme: ESP32-S3, 8 MB PSRAM, SX1262 LoRa radio.

Your browser doesn't support Web Serial. Use a Chromium-based browser (Chrome, Edge, Brave, Opera) on a desktop OS. Firefox and Safari don't ship Web Serial yet.

T-Beam Supreme LR — LR1121

Same board, LR1121 wide-band LoRa front-end (sub-GHz + 2.4 GHz).

Your browser doesn't support Web Serial. Use a Chromium-based browser (Chrome, Edge, Brave, Opera) on a desktop OS. Firefox and Safari don't ship Web Serial yet.

What this does

  • Downloads the latest .factory.bin from the latest release.
  • Asks you to pick the USB-serial port the device shows up on.
  • Erases the flash and writes the full image (bootloader, partition table, app) in one shot.
  • Reboots the device and, over the same USB-serial port, prompts you for the SSID + password of the WiFi network you want it on (Improv WiFi).
  • Once the device joins, the page hands you back a link straight to its web UI — no softAP hop required.

Already flashed? Reconfigure WiFi without re-flashing

If a device is already running this firmware and you just need to move it to a different network — or you flashed it on one machine and want to set credentials from another — plug the device in, click the same install button above, pick its port, and choose Configure WiFi in the dialog that appears. The button automatically detects an already-flashed device over Improv and offers configure / logs / visit options instead of re-flashing.

If the device isn't recognised

  • Try a different USB-C cable — some are charge-only and don't carry data.
  • If the chip never appears in the port list, hold the BOOT button while plugging in to force ROM download mode.
  • On Linux you may need sudo usermod -aG dialout $USER (then log out + back in) for the browser to see the port.
