Add a WiFi network

Pick a network for this device to join. The device transitions to the new network in place, no reboot needed. If the saved network isn't reachable on next boot, the softAP comes up automatically after ~3 minutes as a recovery channel.

Add a TCP client

Connect outbound to another Reticulum node by hostname or IP. The link comes up immediately and persists across reboots.

A TCP client is an outbound link only — this device opens the connection. Peers can't reach back through it, so it can't be publicly advertised the way a LoRa or UDP interface can.
